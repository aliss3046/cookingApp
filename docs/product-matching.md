# Подбор товаров магазина под ингредиент

Статус: реализация `prices/matching.py`. Решения: [ADR-0007](adr/0007-product-matching.md).

Задача: по ингредиенту («молоко») и товарам, которые вернул поиск магазина («Молоко «Простоквашино»
пастеризованное 3,2%, 930 мл»), решить, какие из них и правда молоко, и оставить короткий список,
из которого пара выберет марку и вариант.

## Поток

```
ингредиент ──► провайдер магазина: search(название, адрес) ──► карточки товаров
                                                                   │ prices.normalize (цена, фасовка, способ продажи, марка)
                                                                   ▼
                                                    Matcher.match: оценка и вердикт на каждый товар
                                                                   ▼
                                                    Matcher.shortlist: лучшие по маркам и вариантам
                                                                   ▼
                                       products + ingredient_product_map (source=rule, confidence=оценка)
```

## Как оценивается товар

Сначала **отказы** (любой из них даёт `reject` и причину), потом **оценка** для прошедших.

Отказы:

| Причина | Пример |
|---|---|
| название товара — другой ингредиент справочника | «Шоколад молочный» для молока: справочник относит его к шоколаду |
| не продукт питания (по категории или словам) | «Корм для собак с говядиной» |
| другая форма: консервированный, замороженный, сушёный, маринованный, копчёный, вяленый, солёный, квашеный, жареный | «Томаты в собственном соку» для свежего помидора; «Филе копчёное» для куриного филе |
| слово-исключение ингредиента из правил | |
| название ничего не говорит о продукте | «Набор для пикника» |

Оценка (0..1) у прошедших:

| Признак | Влияние |
|---|---|
| все слова названия товара (без марки, фасовки, процентов, безобидных слов) — это название ингредиента | база 0,90 |
| одно лишнее слово-описание | база 0,75 |
| два и больше | база 0,60 |
| «марка» (слово с заглавной буквы, латиница, текст в кавычках) | не считается лишним словом |
| название ингредиента стоит в начале | +0,05 |
| категория магазина подходит группе ингредиента | +0,05; неизвестная категория: 0 |
| фасовка вне правдоподобной для группы | −0,30 |
| ингредиент выбран по положению слова при равенстве | не больше 0,55 |

Вердикт: **`auto` ≥ 0,85** (в список без вопросов), **`confirm` ≥ 0,60** (в список с пометкой, пара
подтверждает при первом использовании), иначе `reject`. Пороги — константы, их меняет только решение
по эталонному набору.

Общие ингредиенты («рис», «макароны») принимают виды из правил (`includes`): «рис» принимает
длиннозёрный, круглозёрный и басмати. Обратное неверно: «рис длиннозёрный» принимает только свой вид.

## Вариант и марка

- **Марка**: текст в кавычках или слово из списка известных марок. Не определилась — пусто (отдельная «марка без названия»).
- **Вариант**: процент из названия, нормализованный (`3,2%`). Диапазон («3,4-4,5%») сохраняется как есть.
- Короткий список: для каждой пары (марка, вариант) в каждом магазине лучшие 2 фасовки; всего не более 12 на ингредиент и магазин.

## Что ещё не решено

- **Реальные категории магазинов неизвестны**: таблица «категория → группа» составлена по здравому смыслу и не
  проверена, пока нет провайдеров (они заблокированы условиями использования). Пока категория неизвестна или не
  опознана, она не влияет на оценку.
- **Список известных марок** пуст по умолчанию (в тестах небольшой). Марка с заглавной буквы определяется и так.
- **Эталонный набор синтетический**: названия составлены по типичным, не скачаны с сайтов. Он защищает от регрессий
  и показывает слабые места правил, но не заменяет проверку на настоящем ассортименте.

## Эталонный набор и метрики

`tests/prices/fixtures/match_golden.json`: по ингредиентам список «подходит» и «не подходит» (включая сложные
отрицательные: шоколад «молочный», сок «яблочный», уксус «яблочный»). Жёсткие требования в CI:

1. Ни один товар «не подходит» не получает `auto`.
2. Доля верных среди `auto` — 100%.
3. Полнота (подходящие товары с вердиктом `auto` или `confirm`) не ниже порога, записанного в тесте.

Текущие цифры и честная оговорка про то, как они получены, — в [prices/README.md](../prices/README.md).

Правило «ингредиент должен стоять первым словом» (`not_head`) отсекает «Чипсы со вкусом сыра», «Пирог со сметаной»,
«Чай с лимоном»: когда ингредиент упомянут позже, это другой продукт. Цена правила: товары, где продукт назван не
первым («Говядина» после определения, «Свежие помидоры» после слова вне списка безобидных), уходят на проверку или
отвергаются.
