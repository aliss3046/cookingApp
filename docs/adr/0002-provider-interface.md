# ADR-0002: Внешние сервисы за интерфейсами

Статус: предложено

**Выбрано:** магазины — `PriceProvider` (`search`, `get_product`, `list_category`); источники рецептов и LLM — собственные интерфейсы. Остальной код знает только интерфейс и таблицу `prices`. Резервный провайдер — ручной ввод и чеки.

**Почему:** сайты магазинов меняются и могут запретить сбор; смена провайдера не должна трогать остальной код.

**Альтернативы:** вшить парсеры в расчёт корзины (хрупко, не тестируется без сети).
