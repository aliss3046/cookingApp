# ADR-0003: Цены только добавляются

Статус: предложено

**Выбрано:** `prices` — INSERT-only; ключ запроса включает `location_id`; устаревание (старше 3 дней) вычисляется на чтении и помечается, не скрывается.

**Почему:** видна динамика, легко находить устаревшие данные, цена зависит от адреса.

**Альтернативы:** UPSERT последней цены (теряет историю и диагностику парсера).
