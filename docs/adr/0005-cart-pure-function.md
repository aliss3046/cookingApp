# ADR-0005: Корзина — чистая функция

Статус: предложено

**Выбрано:** расчёт корзины живёт в `core/` без доступа к сети и БД; подбор товаров и округление до упаковок принимают уже загруженные данные. Остаток от упаковки сохраняется как `pantry.source = leftover`.

**Почему:** тесты на 100% веток и 15+ сценариев без сети.

**Альтернативы:** считать корзину SQL-запросами (сложно тестировать граничные случаи).
