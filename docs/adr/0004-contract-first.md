# ADR-0004: Контракт API первичен

Статус: предложено

**Выбрано:** `docs/openapi.yaml` пишется до реализации, версия в пути `/v1/`, ломающие изменения только в новой версии. Тяжёлые операции асинхронные (`202` + `job_id`). Совместное редактирование — через Supabase Realtime.

**Почему:** фронтенд пишет другой разработчик и должен работать по контракту и моку без ожидания бэкенда.

**Альтернативы:** код-фёрст с автогенерацией схемы (контракт дрейфует вслед за реализацией).
