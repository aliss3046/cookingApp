# prices/ — Python

Цены магазинов. Связь с Go API только через базу (таблицы `products`, `prices`, `jobs`),
см. [ADR-0006](../docs/adr/0006-go-api-python-workers.md).

## Что есть

`normalize.py` — нормализация текста карточки товара, без сети:

| Функция | Пример |
|---|---|
| `parse_price` | `«129 99 ₽»` -> 129.99 (рубли и копейки раздельно), `«1 299,90 ₽»` -> 1299.90 |
| `parse_pack` | `«Молоко 3,2%, 930 мл»` -> 930 мл; `«Йогурт 4 x 125 г»` -> 500 г; `«Яйцо С1, 10 шт»` -> 10 шт |
| `parse_price_per_kg` | `«199,90 ₽/кг»`, `«за 100 г 19,99 ₽»` -> 199.90 за кг; литр считается как кг |
| `detect_sale_mode` | `pack_mass`, `pack_count`, `per_piece`, `by_weight`, `unknown` (как `domain.SaleMode` в Go) |
| `extract_brand` | марка в кавычках или самая длинная известная марка |
| `normalize_offer` | `RawOffer` (текст карточки) -> `NormalizedOffer` (строки для `products` и `prices`) |

Деньги — `Decimal`. Нечитаемая основная цена — `PriceParseError`: товар пропускается, воркер
считает такие случаи для алерта о смене вёрстки (план: падение числа разобранных товаров больше 30%).

## Подбор товаров под ингредиент

`matching.py`, правила в `matching_rules.json`. Алгоритм и причины решений: [docs/product-matching.md](../docs/product-matching.md),
[ADR-0007](../docs/adr/0007-product-matching.md). Точность важнее полноты: сомнительное уходит паре на подтверждение.

```python
matcher = Matcher(load_directory())
matcher.match(
    "milk", offer
)  # Match: оценка 0..1, вердикт auto / confirm / reject, марка, вариант, причины
matcher.shortlist("milk", offers)  # лучшие по (магазин, марка, вариант), не больше 12
```

### Качество на эталонном наборе

`tests/prices/fixtures/match_golden.json`: 32 ингредиента, 246 названий (102 подходят, 144 нет, среди них нарочно сложные:
«шоколад молочный», «сок яблочный», «уксус яблочный», «лук красный»).

| Показатель | Значение |
|---|---|
| Неподходящий товар получил `auto` | 0 из 144 |
| Неподходящий товар дошёл до `confirm` | 1 из 144 («Мёд-суфле») |
| Точность `auto` | 88 из 88 |
| Подходящие: `auto` | 88 из 102 (86%) |
| Подходящие: `auto` или `confirm` | 102 из 102 |

**Как читать эти цифры.** Набор составлен мной, до подгонки правил, но правила потом исправлялись по его ошибкам
(например, слова «красный» и «домашнему» сначала стёрли отличие красного лука и отвергали «домашнее молоко»).
Поэтому цифры показывают, что правила не регрессируют и согласованы со справочником, а не качество на настоящем
ассортименте: названия синтетические, магазины и их категории пока недоступны.

### Что подтверждается парой, а не решается автоматически

Названия с одним незнакомым словом получают `confirm`: «Помидоры красные», «Макароны рожки», «Мёд липовый»,
«Томаты сливовидные». Это цена принципа «точность важнее полноты»: слов-разновидностей слишком много, чтобы
считать их безобидными.

### Требует решений в других частях

В БД: `products.variant`, убрать `ingredient_product_map.confirmed_by_couple`, добавить `source` и `matcher_version`,
таблица отказов пары. В Go-корзине: вариант как второй выбор после марки. Подробнее в ADR-0007 (в `docs/schema.md`
не правится, чтобы не конфликтовать с PR #2).

## Конвейер цен: читать магазин сразу, без отдельных «провайдеров»

Что читать, задаёт профиль магазина (`stores.json`), как читать, определяют форматы данных страницы
(`listing.py`). Никакого кода под конкретный магазин.

```
профиль магазина ──► PoliteFetcher (robots.txt, пауза ≥ 20 с, суточный лимит, остановка при блокировке)
   страницы категорий ──► listing.extract_offers (Nuxt, Next.js, JSON-LD) ──► normalize_offer
   ──► Matcher.shortlist по ингредиентам категории ──► PriceStore (товары, цены, сопоставление)
```

```bash
# 1. без сети: разобрать сохранённую страницу и посмотреть, что подберётся
python -m prices dry-run --store magnit --html page.html --groups овощи,молочные
python -m prices categories --html page.html          # дерево категорий, чтобы выбрать адреса

# 2. с сетью: только для магазина, включённого владельцем проекта
python -m prices run --store magnit --location 992301 --json result.json
```

### Загрузка страниц: один интерфейс `get(url)`, источник выбирает профиль

| `source` в профиле | Что делает |
|---|---|
| `http` | `PoliteFetcher`: по сети, `robots.txt`, пауза ≥ 20 с, суточный лимит, остановка при блокировке |
| `saved` | `SavedPages`: читает страницы, сохранённые человеком из браузера, из `pages_dir` (по умолчанию `prices/pages/<магазин>/`, в git не попадает) |

Разбор, нормализация и подбор не зависят от источника. Подмены TLS-отпечатка, stealth-режима и скрытых браузеров
в проекте нет намеренно: отказ магазина (403) останавливает загрузку, а не обходится. Флаг `--pages-dir` переопределяет источник.

### Магнит и Дикси включены (личное использование)

Решение владельца 14.10.2026: личное использование, без монетизации; запись `approval` лежит в `stores.json`.

| Магазин | Как читаются страницы | Формат |
|---|---|---|
| Магнит | `python -m prices run --store magnit --location 992301` (сеть, пауза 20 с) | Nuxt, адреса `/catalog/{id}-{code}?shopCode=…&shopType=dostavka` |
| Дикси | `source: saved`: страницы сохраняются из обычного браузера в `prices/pages/dixy/`, затем `python -m prices run --store dixy --location 1` | HTML `article.card` |

Простой клиент получает у Дикси 403: это не обходится (ни подмены User-Agent, ни скрытых запросов). Имя файла в папке
берётся из пути адреса (`/catalog/ovoshchi-frukty/ovoshchi/` → `catalog_ovoshchi-frukty_ovoshchi.html`).
Результат (`--json`) содержит по каждому ингредиенту подобранные товары с названием и ценой.

Дерево категорий Магнита с id: `python -m prices categories --html страница.html`.

### Как включить другой магазин

Остальные магазины выключены до решения владельца проекта (см. [docs/stores.md](../docs/stores.md)).
Чтобы включить, в профиль добавляют `"enabled": true` и запись об одобрении, без неё конфигурация не загружается:

```json
"approval": {"by": "кто принял решение", "on": "ГГГГ-ММ-ДД", "basis": "на каком основании"},
"categories": [{"url": "https://magnit.ru/...", "groups": ["молочные"], "note": "Молоко"}]
```

Адреса категорий пишутся явно (только `https` и только на сайте магазина).

### Что гарантирует код

| Правило | Как |
|---|---|
| `robots.txt` соблюдается | свой разбор с шаблонами `*` и `$`; нечитаемый `robots.txt` (403) значит «нельзя» и останавливает магазин |
| Нагрузка | не чаще раза в 20 с на сайт (пол, ниже нельзя), `Crawl-delay` из robots.txt повышает паузу, суточный потолок до 500 запросов |
| Блокировка не обходится | 401/403/429 и страницы-заглушки («проверьте VPN», captcha) останавливают работу с магазином, повторов и подмены User-Agent нет |
| Внутренние интерфейсы не используются | читается только то, что сайт кладёт в страницу для отображения (`/api/`, `/ajax/` запрещены в robots.txt у Ленты и Дикси) |
| Данные защищены от смены вёрстки | если разобрано на 30% и более карточек меньше, чем в прошлый раз, или ни одной, запись пропускается (`suspicious`) |
| Цены только добавляются | `add_prices` — INSERT-only; товары обновляются, сопоставление ингредиента заменяется целиком |

### Что проверено на настоящих данных, а что нет

- **Проверено вживую** (14.10.2026, Магнит, 17 страниц категорий, ~6 минут с паузой 20 с): 552 карточки из 552, ошибок разбора 0,
  220 подобранных пар (134 надёжных, 86 на подтверждение). Молоко, лук, морковь, картофель, томаты, рис подобрались верно, цена за кг считается.
- **Дикси:** HTML-стратегия проверена на настоящей вёрстке (карточки лука, 14.10.2026), но полный прогон по всем категориям не делался:
  страницы нужно сохранить из браузера.
- **Не проверено:** Лента, Пятёрочка, Перекрёсток (недоступны, см. docs/stores.md).
- **Ограничение полноты у Магнита:** постраничный обход запрещён в robots.txt, на странице 33 товара, значит видна только первая страница категории.

## Допущения

- В «129 99» последняя группа из двух цифр — копейки; группа из трёх — тысячи («1 299»).
- Фасовка берётся из последнего упоминания в названии: размер обычно в конце.
- Цена за кг для `pack_mass` без явной цены за кг считается из цены упаковки (`notes: price_per_kg_derived`).
- Марка без кавычек и не из списка известных не определяется: такие товары идут как «без марки».
