# prices/ — Python

Цены магазинов. Связь с Go API только через базу (таблицы `products`, `prices`, `jobs`),
см. [ADR-0006](../docs/adr/0006-go-api-python-workers.md).

## Что есть

`normalize.py` — нормализация текста карточки товара, без сети:

| Функция | Пример |
|---|---|
| `parse_price` | `«129 99 ₽»` -> 129.99 (рубли и копейки раздельно), `«1 299,90 ₽»` -> 1299.90 |
| `parse_pack` | `«Молоко 3,2%, 930 мл»` -> 930 мл; `«Йогурт 4 x 125 г»` -> 500 г; `«Яйцо С1, 10 шт»` -> 10 шт |
| `parse_price_per_kg` | `«199,90 ₽/кг»`, `«за 100 г 19,99 ₽»` -> 199.90 за кг; литр считается как кг |
| `detect_sale_mode` | `pack_mass`, `pack_count`, `per_piece`, `by_weight`, `unknown` (как `domain.SaleMode` в Go) |
| `extract_brand` | марка в кавычках или самая длинная известная марка |
| `normalize_offer` | `RawOffer` (текст карточки) -> `NormalizedOffer` (строки для `products` и `prices`) |

Деньги — `Decimal`. Нечитаемая основная цена — `PriceParseError`: товар пропускается, воркер
считает такие случаи для алерта о смене вёрстки (план: падение числа разобранных товаров больше 30%).

## Не сделано

- Провайдеры Дикси и Ленты: **заблокированы до проверки условий использования** (docs/stores.md).
- Ручной ввод и чеки, подбор товара под ингредиент, воркер по расписанию.

## Допущения

- В «129 99» последняя группа из двух цифр — копейки; группа из трёх — тысячи («1 299»).
- Фасовка берётся из последнего упоминания в названии: размер обычно в конце.
- Цена за кг для `pack_mass` без явной цены за кг считается из цены упаковки (`notes: price_per_kg_derived`).
- Марка без кавычек и не из списка известных не определяется: такие товары идут как «без марки».
