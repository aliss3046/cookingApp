# frontend/

Место для клиентской части. Её пишет отдельный разработчик; бэкенд-агент не создаёт здесь
код, страницы, компоненты, стили и PWA.

## Что фронтенд-разработчик получает от бэкенда

- Контракт: [`docs/openapi.yaml`](../docs/openapi.yaml), версия в пути `/v1/`.
- Мок-сервер с тестовой парой и рецептами (появится в Фазе 1, каталог `tests/mock/`).
- Список кодов ошибок: раздел `ErrorCode` в OpenAPI.
- Описание Realtime-событий: [`docs/architecture.md`](../docs/architecture.md#realtime).
- Staging-окружение (Supabase).

## Правила

- Изменение контракта сначала попадает в OpenAPI и сообщается фронтенд-разработчику.
- Фреймворк выбирает фронтенд-разработчик; бэкенд от него не зависит.
- Секреты и ключи сюда не коммитятся.
